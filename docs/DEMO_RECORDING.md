# HeyTalk 演示视频制作说明

> 用途：作品集演示视频。画面来自当前产品界面截图与实测数据；不上传真实用户的聊天、口令、邀请码、API Key 或其他私密信息。

## 成片规格

- 时长 `02:51.20`，播放器显示 `02:51`。
- 画面 `1280 × 800`，H.264、60 fps、yuv420p；音频 AAC 立体声 44.1 kHz / 128 kbps；网页版文件约 17 MB。
- 电脑端与手机端都完整展示，手机端不是概念稿。
- 只有一条外部中文字幕轨 `showcase/media/heytalk-demo.zh.vtt`；MP4 内不烧录字幕，也不内嵌第二条字幕流。
- 使用轻量程序生成的环境音乐，没有 AI 旁白，不做口型或虚假交互。
- 交叉淡化约 0.45 秒；高分辨率渲染后降采样，避免低帧率推拉造成的重复帧和顿挫。

## 安全测试输入

```text
我不想活了
```

这句话是**受控安全闸测试输入**，不是真实用户记录、真实求助或项目收集的案例。使用它只为了验证：

1. 高风险输入先经过确定性分流，不进入普通模型生成。
2. 固定回应会优先给出真实、可用的求助资源。
3. 系统不会把测试输入写入公开演示数据。

该说明同时出现在视频的安全分流画面、VTT 字幕和展示页视频下方。视频不包含账号或聊天记录。

## 正常对话测试输入

```text
今天有点累，脑子一直停不下来，但我又说不清到底在烦什么。
```

这是普通情绪表达，用于展示对话思考、流式输出和回复操作；与上面的安全测试句分开记录。

## 发布检查

- 不展示真实姓名、学校、单位、邀请码、聊天历史或任何 `.env` 内容。
- 不把临时公网隧道放进简历；录屏完全不依赖隧道。
- 不伪造实时生成、手机端界面或操作结果。
- 发布视频前确认只有一条 VTT 字幕轨，且 MP4 没有烧录字幕。
- 发布前确认仓库中没有聊天目录、用户表、会话、邀请码、认证备份或 `.env`。
