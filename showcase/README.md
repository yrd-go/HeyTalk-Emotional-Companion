# HeyTalk showcase

这是 HeyTalk 的静态作品集页面，不依赖 React、CDN 或外部字体。页面内包含
`01:08` 的电脑端与手机端演示。

本地预览：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/preview_showcase.ps1
```

录屏与页面素材：

- `assets/desktop-home.png`
- `assets/desktop-chat.png`
- `assets/mobile-home.png`
- `media/heytalk-demo.mp4`：H.264 / AAC，`1280 × 720`，24 fps，67.9 秒；单条 AI 中文旁白音轨；MP4 内未烧录字幕

安全分流片段中的“我不想活了”是受控演示测试输入，不是真实用户记录。该片段用于验证高风险输入会直接命中固定安全回应与真实求助渠道。
